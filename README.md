# CodeAlpha Internship Projects

This repository contains all the projects completed as part of the CodeAlpha internship program. Each folder represents a task assigned during a specific month of the internship.

---

## 📂 Project Overview

### 📊 Month 1: EDA on Unemployment Rate
- **Folder:** `CodeAlpha_EDA_ON_Unemployement_Rate`
- Performed Exploratory Data Analysis (EDA) on unemployment data
- Analyzed trends, patterns, and insights using visualizations

---

### 🚗 Month 2: Car Price Prediction
- **Folder:** `CodeAlpha_Car_Price_Prediction`
- Built a machine learning model to predict car prices
- Applied data preprocessing, feature selection, and regression techniques

---

### 🧪 Month 3: A/B Testing Analysis
- **Folder:** `CodeAlpha_AB_Testing`
- Performed statistical analysis to compare control and treatment groups
- Calculated conversion rates and conducted hypothesis testing (t-test)
- Derived data-driven conclusions for decision making

---
